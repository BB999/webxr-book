作例ギャラリー

この本で作る4つの作品です。Quest のブラウザで開いて、「VR で遊ぶ」か「MR で遊ぶ」ボタンを押してください。

  • 第3章VR宇宙に浮かぶ惑星
  • 第4章VR風船わりゲーム
  • 第5章MR部屋にねこびを置こう
  • 第6章MR部屋でボール遊び

第5・6章の作品は、Quest の「スペース設定」を済ませておくと、床や机、壁を使って遊べます。

特典のダウンロード

テンプレート、各章のスタート地点と完成版、ねこびの 3D モデル、プロンプト集を、1つの zip ファイルにまとめています。Mac でダウンロードしてください。

特典をダウンロードする（zip）

zip はダブルクリックで開きます。フォルダーは、Mac の好きな場所にコピーしてから、VS Code で開いてください。くわしくは、本の第1章と第3章（3-1）を見てください。
